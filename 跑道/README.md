# 跑道 · 跑团终端（人类裁定版）

一条命令起一局：**你写操作声明 → KP（云端 qwen3.8:27b）推演 → 你选一个走向或打回 → 落地进台账 md → 下一回合再读这些 md。**

## 三层分工

| 层 | 谁 | 说明 |
|---|---|---|
| 推演 | 云端 `qwen3.8:27b` | 思考与产出分离：`reasoning` 归后台（丢弃），`content` 归裁定 |
| 取材 / 校验 | canon 的**同一份实现** | `mcp-canon/canon-tools.mjs`（MCP 服务器只是它的 stdio 传输壳）。`pickChar` 认全名/姓/舞台名/罗马音；`who` 当语言指纹闸门 |
| 裁定 | **你** | 选编号 / 打回重推 / 同意后落地。模型不拍板 |

**上下文铁律**：模型不携带上一回合的思考。它的记忆就是 `台账/*.md`；每回合从磁盘重新装配，读完即丢弃。

## 命令

```bash
node 跑道/跑道.mjs                           # 交互式（真终端里带颜色）
node 跑道/跑道.mjs --脚本 跑道/_演示脚本.txt    # 脚本模式：逐行 await，可复现（推荐演示/回归）
node 跑道/跑道.mjs --探端点                   # 只测网关，不建台账
node 跑道/跑道.mjs --装配 --act "打工"         # 只看工作台（不调模型）
node 跑道/跑道.mjs --状态 ｜ --档 幕 ｜ --初始化
node 跑道/跑道.mjs --工具 char '{"name":"祥子"}'   # 直接调 canon 工具
node 跑道/_闸门核对.mjs 2                     # 用满 topK 复算某回合的语言指纹
```

交互式里：任意文本 = 操作声明 ｜ `编号` = 选定 ｜ `打回 理由` = 重推（进废案）｜ `:状态` `:档 幕` `:工具 …` `:退出`

## 台账（模型的全部记忆，就是这几个文件）

```
台账/世界.md    真相层（KP 全知，append-only；只追加「已触发」）
台账/幕.md      当前场景（**唯一可覆写**的文件）
台账/时间线.md  不可逆事实（append-only）
台账/手记.md    玩家已知（✅事实 / ❓玩家以为 / ❌已推翻）
台账/废案.md    被否的走向与理由（只有人类读这一份）
台账/局.json    回合数 / 打回数 / 历史
台账/回合/第N回合.md   全记录：推演 + 候选 + 裁定 + 演出 + 闸门 + 上下文体检
```

`append-only` 是硬规矩：除了 `幕.md`，一律只追加。否则几回合后这份台账就不再是 log，复盘时你会不知道哪一版是真的。

## 闸门（canon `who` + 投影三律）

- **非数据律**：演出里不许出现判定/骰子/分数/选项等后台词形（禁词表在 `跑道.mjs`）
- **语言指纹**：`who` 用满 **topK=25** 打分，给出「本人第几名 / 偏差 / **最大偏差项**」——最大偏差项就是打回时该写的理由
- **样本量提示**：`who` 自己的口径是「句数越多越稳」。少于 4 句时排名落在噪声区间，此时只提示、不判失败
- **世界是闭的**：工作台里写死在册 25 人 + 泛用配角白名单，禁止新造人物

## 凭据（只存一处）

`autodl-接入信息.md`。环境变量 `AUTODL_BASE_URL` / `AUTODL_API_KEY` / `AUTODL_MODEL` 优先。
**只用那个文件里的端点与 `qwen3.8:27b`**；接入页里列的 `qwen3.8:27b-q8_0` 实际不存在（404）。

> 🚨 **零并发**：远端 `llama-server -np 1`，全局 1 个 slot。**串行派发，别并发**——并发只会排队，
> 看起来像服务挂了（实测短请求排队 3 分 42 秒）。decode ≈ 20 tok/s，一回合（推演+演出）
> 实测 4~5 分钟、思考流 5k~13k 字全部丢弃。

## 传输层

走 **SSE 流式**（`stream: true`），与 `订单队列/queue.mjs` 同一条踩过的路：这个网关对**长**非流式
请求会 `fetch failed`（`/v1/models` 却秒通）。流式还顺带给了进度——20 tok/s 下不至于对着黑屏等三分钟。

## 已知边界

1. **一回合 = 2 次模型调用**（推演 + 演出），4~5 分钟。零并发下没有并行空间。
2. **打回会整局重掷**：新一版的「真相」可能与上一版冲突（上一版只进废案，不进世界）。想让打回只改走向不改真相，需要把 `真相` 也纳入台账。
3. **闸门只看台词，不看旁白**：旁白没有语言指纹基准，目前只受非数据律约束。
4. **未接入 stdio MCP 传输**：`跑道` 直接 import `canon-tools.mjs`（MCP 服务器包的就是它）。本沙箱下 Node spawn + 管道 stdio 会 EPERM，所以没走 spawn；要真的走 JSON-RPC 线，得用 `autodl-qwen-dsh/serial_dispatch.mjs` 那类本机中转。
