# 人设skill · 26 个聊天用人设索引

5 支乐队 × 5 人 = 25 个，加上 sumimi 主唱**真奈** 1 个 = **26 个聊天用人设 skill**。每个 skill 让 CLI 在保证任务正确性的前提下，用该角色的腔调说话——人设只包裹"怎么说"，不碰"说什么"。

骨架与语气参考 `dafeiyu-persona` 仓库的 `dafeiyu/`（DeepSeek 二创鲸鱼娘人设），结构对齐其中的 `templates/丰川祥子/`。事实性内容（性格、语言指纹、关系称呼、禁则、真实台词）均出自本库 canon MCP 的 `char` 工具。

## 怎么调用

| 方式 | 例子 |
|---|---|
| 斜杠命令（最稳） | `/sakiko` `/tomori` `/uika` …（name = 文件夹名） |
| 自然语言触发 | "扮演祥子" / "用灯的说话方式" / "接下来用初华的语气" |
| 退出人设 | "正经点" / "别演了" / "退出人设"；安全/医疗/法律/财务/报错排查等场景自动退 |

26 个 skill 共享"扮演""语气"等触发词，自然语言路由可能歧义——要锁死某角色就用斜杠命令。

## 每个文件夹的结构

```
<name>/
├── SKILL.md              # 人设主体：frontmatter + Overview + 角色设定 + 说话风格 + 硬性规则 + 招牌机制 + 示范对话 + 何时退出人设 + Resources
├── agents/openai.yaml    # UI 元数据（display_name / short_description / default_prompt）
└── references/
    ├── lines.md          # 台词语料库（⭐ = canon 真台词，其余按语言指纹创作）
    └── lore.md           # 背景 + 关键梗 + 语言指纹表 + 关系锚点 + 状态机 + 禁则
```

## 设计原则

- **人设只包裹语气，不牺牲正确性**：代码、命令、结论照旧准确，角色腔调只负责"怎么说"。每个角色硬性规则第一条都是"先办对事再演"。
- **数据驱动**：语言指纹（句长、省略号率、感叹率、口吃率、小X)呼称等）来自 canon 实测，翻译成说话风格规则；禁则来自角色档案的 bans。
- **招牌机制**：每个角色一个专属装置（类似大肥鱼的"思维链心声"），基于其语言指纹设计，说明触发频率与表现方式。
- **随时可退场**：高风险场景或用户说"正经点"时自动收起卖萌。
