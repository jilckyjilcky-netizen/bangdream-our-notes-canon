# 角色模型 / Character Persona Models

从 `素材全量/` 的全剧本语料中**实证构建**的角色扮演模型。
不是 wiki 人设的转述，而是「**先说数据，再说人**」。

## 方法论：为什么这份模型不一样

普通的角色扮演设定来自**印象**（"她很内向、说话很小声"）。
这里每一条断言都来自**计数**，并且经过两道检验：

### 第一道 —— 逐字校验

模型文档里所有 `「引文」` 都会被拿去原始语料中做逐字定位：

```bash
node 工具/verify_quotes.mjs 角色模型/高松灯_角色扮演模型.md \
  素材全量/按角色/zh-Hans/MyGO/灯_高松灯.md \
  素材全量/角色台词补充/zh-Hans/按角色/灯_高松灯.md
```

当前结果：**96 条引文 / 96 命中 / 100%**。
（任何二手转述、记错、编造的句子都会在这里暴露。）

### 第二道 —— 横向对照

单看"灯省略号率 84.6%"无法判断这是不是她的特征——**万一所有人都这样呢？**
所以同一套算法要跑满 25 名主角色，看排名。

结论：省略号率 25 人中位数约 41%，**灯是全场唯一突破 80% 的角色**（第 2 名 64.5%）。
→ 这个指标确实是她独有的指纹，可以写进模型当硬规则。

**这道检验也可能推翻断言。** 例如"用沉默说话"一开始以为是灯独有，
横比后发现若叶睦（13.6%）、要乐奈（11.3%）都紧贴在她身后——
说明那是这一代人物的**共同语法**，灯只是把它推到了极致。
模型里因此把它改写成"第 1 名，但非独有"，而不是"只有她会这样"。

### 第三道 —— 扮演结果回测（闭环）

模型生成的对话，回头用**同一套指标**打分：

```bash
node 工具/persona_check.mjs 角色模型/示例_小爱带灯去吃冰淇淋.md 灯 \
  素材全量/按角色/zh-Hans/MyGO/灯_高松灯.md
```

输出 9 项指标的「语料真值 / 本次生成 / 允许区间 / 判定」。
**容差随样本量自动放宽**（n≥60 ×1.0，n≥30 ×1.3，否则 ×1.7）——小样本指标波动大，只宜看趋势。

这道检验在实战中抓出了三类错误，**都是人眼看不出来的**：

| 抓出的问题 | 真值 | 首稿 | 病根 |
|---|---|---|---|
| 灯「以 `…` 结尾」偏低 | 42.4% | 17.4% | 我把话说得太圆了 |
| **爱音被写短** | 均长 13.6 | 7.7 | 场景的 2 倍反差被压平成 1.2 倍，质感塌了 |
| 爱音省略号率偏低 | 37.6% | 11.4% | 我写得太干脆，漏掉她的犹豫与话头衔接 |

第二条尤其值得注意：**它抓的不是主角，是配角**——主角单看没问题，
但整场戏因为配角被写平而失去了对比度。

## 统一的度量口径

跨角色比较必须在同一口径下，否则数字没有意义。本项目固定：

| 指标 | 定义 |
|---|---|
| **句长** | **纯汉字数**（剔除标点、空白）。括注的"含标点"口径不用于横比 |
| **台词** | 已剔除：纯歌词（`『…』`）、纯心声（`（…）`）、纯省略号行 |
| **沉默占比** | 分母为**该角色全部条目数**；分子为不含汉字的条目（`…………` 与 `……？` 皆计） |
| **省略号率 / 疑问率 / 感叹率 / 口吃率** | 分母为**台词条目数** |

> ⚠️ 口径不同会得出差一倍的结论（灯句长"含标点 10.0"vs"纯汉字 6.7"）。
> 改动口径时，`persona_stats.mjs` 与 `persona_compare.mjs` **必须同时改**。

## 为其他角色建模型

工具是通用的，25 名主角色都能跑：

```bash
# 1) 单角色语言指纹
node 工具/persona_stats.mjs '素材全量/按角色/zh-Hans/MyGO/爱音_千早爱音.md'

# 2) 全角色横向对比（决定哪些指标可以当硬规则）
node 工具/persona_compare.mjs

# 3) 写完后校验引文
node 工具/verify_quotes.mjs 角色模型/某某_角色扮演模型.md <该角色的语料md...>
```

**换角色时的顺序建议**：先跑 (2) 看该角色的指标在 25 人里排第几 →
只把**排名靠前或靠后**的指标写进"硬规则"，中游指标不要当特征写。

## 已知局限

| 局限 | 说明 |
|---|---|
| **样本量** | 单角色语料 400–1600 条，但拆到"分关系"（每对 40–50 条）后样本偏小，**趋势可信、精确到小数点不可信** |
| **翻译腔** | zh-Hans 是官方简中，日文原语的语气（如 `私`／终助词）在译文中有损耗。需要更细的语气判定时应并读 `按角色/ja/` |
| **游戏文本 ≠ 小说文本** | 语料是对话体，缺少叙述层。改写进小说时"动作描写"部分没有语料依据，属于合理外推 |
| **未涵盖** | 动画/剧场版剧情不在本数据库内（本项目只提取了 Our Notes 游戏剧本） |
