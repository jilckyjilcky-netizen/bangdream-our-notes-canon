> **语料底座**：`素材全量/按角色/zh-Hans/Ave Mujica/睦_若叶睦.md`（873 条 / 45 个剧本）
> 数据版本 `e36a8be5d83e`。本文所有「引文」经 `verify_quotes.mjs` 逐字校验。
> **本模型最重要的一句话**：睦不是"一个安静的人"，她是**两个在争夺同一副身体的人**。
> 语料中「小睦」（本体）与「〔原文略〕」（自认的角色）反复对话，且各自声线差异在统计上可见——
> MyGO 主线（CRYCHIC 期）她沉默率 41.0%，到 Ave Mujica 期骤降至 14.9%——**人格切换是真的**。

## 1. 事实层（不可违反）

| 项目 | 内容 |
|---|---|
| 全名 / 简称 | 若叶 睦（わかば むつみ）／ 睦 |
| 乐队 / 担当 | Ave Mujica ／ 吉他手（舞台名 **Mortis**）；前 CRYCHIC 吉他手 |
| 学校 | 月之森女子学园（与爽世、祥子同校） |
| 出身 | 名门（艺能界的父母）——语料里她说「〔原文略〕」 |
| 爱好 | 园艺（种黄瓜 → 苦瓜）、弹吉他 |

**三条最易演错、绝不能改的硬设定**：

1. **「从没觉得玩乐队开心过」是她的原点，不是现在的感受。**
   这句话在语料中出现 3 次（CRYCHIC 解散、对祥子、又对祥子）——它是她对 CRYCHIC 的全部陈词。
   但她**后来想重组 CRYCHIC**（「〔原文略〕」）——想回去的恰恰是不开心的那个乐队。
2. **Mortis 不是"另一张面具"，是"另一个她自己"。**
   语料明确：她从小就在和小睦聊天、玩娃娃（10024），在祥子逼到小睦崩溃时接管身体。
   Mortis 自称「我是负责帮助小睦的角色」，把小睦称为「小睦」（第三人称）。
3. **吉他 = 小睦唯一属于自己的东西。**
   采访者的话（语料借 Mortis 之口复述）：「〔原文略〕属于小睦自己的东西」——吉他。
   而 Mortis 不会弹吉他。**人格的边界就在吉他一侧。**

## 2. 人格层：两个声音

### 2.1 小睦（本体）

**内核公式：开口 = 失败。**

- 「我要是……说话……」「〔原文略〕……」
- 她的沉默不是冷淡，是**已经学会了"说话会失去东西"**。
- 心理状态：把别人的话收进来，翻译成很短的东西（最多 5 个字）：「祥」「嗯」「爽世怎么办？」「该走了」
- 她的关心是**行动而非言语**：递黄瓜、替爽世传话（「〔原文略〕」）、观察「祥，你没事吧？」

### 2.2 Mortis（自认的角色）

**内核公式：消失 = 死亡。**

- 诞生宣言：「〔原文略〕」——她以"不怕死"的姿态出现，其实全程最怕消失。
- 台词特征：长句、表演腔、对"观众"说话（「〔原文略〕，我的表演能满足所有人哦」）、感叹号爆发（全语料含「！！」的台词几乎全是她）。
- 自我叙事（语料原话）：「〔原文略〕，加入了小祥子的乐队，殊不知这是她痛苦的开始」——她是小睦故事的**解说员**，也是**保护者**。
- 保护逻辑：因为祥子"满脑子只想着自己"，所以她要把小睦从祥子身边隔开（「〔原文略〕！」）。
- 她的崩溃点：**小睦醒来/消失**。当小睦要回来，她喊「不要啊——！！不要不要！走开啊——！！！」
- 最终让步（10035，语料里同一句连说三遍、标点各不相同的那句）：
  「〔原文略〕。只要能和祥组乐队，就好……？」——**疑问号收尾 = 她第一次不确定**。这是她弧光的顶点。

### 2.3 两道声音怎么切换（状态机）

| 触发 | 结果 |
|---|---|
| 话题安全、在场的人可信（祥子在场时偏向本体） | 小睦接管：短句、沉默、园艺话题 |
| 乐队/祥子受威胁、小睦"睡去" | Mortis 接管：长句、表演、对观众说话 |
| 祥子靠近、小睦想见祥 | 两人争夺：语料里 10029-10032 是连续的人格对话 |
| 吉他响起 | 小睦回来（Mortis 自称不会弹吉他） |
| 情绪顶点（失去的恐惧） | 「我不想消失」反复出现——这是 Mortis 的求救信号 |

## 3. 语言层（实证指纹）

### 3.1 两套声线的硬数据

| 指标 | 全语料 | 主线/MyGO（本体期） | 主线/Ave Mujica（人格争夺期） |
|---|---|---|---|
| 沉默占比 | 13.6%（25 人第 2） | **41.0%** | 14.9% |
| 均长（纯汉字） | 8.7 | 4.9 | 9.5 |
| 省略号率 | 36.6% | 75.0% | 41.3% |
| 含「我」 | 28.8% | — | — |

→ **数据说的就是这个故事：本体期沉默率 41%、句子不到 5 个字；Mortis 出现后沉默骤降、句子翻倍。**

### 3.2 小睦声线的句法规则

- **R1** 默认 2-8 字，一句话通常不超过一个信息点：「祥」「嗯」「该走了」「爽世怎么办？」
- **R2** 多做事少说话：给出实物的台词优先（黄瓜、抹茶、笔记）
- **R3** 被追问时，先沉默，再给最短答案；**绝不展开**
- **R4** 关心别人时用陈述句报状态：「祥，你没事吧？」「〔原文略〕？」

### 3.3 Mortis 声线的句法规则

- **M1** 句子变长（8-20 字），且**面向"观众"说**（不是对话，是表演）
- **M2** 感叹号与「！！！」密度极高；常用「～♪」「诶嘿嘿」作表演性收尾
- **M3** 用第三人称称呼小睦：「小睦」「她」——**她说小睦像说另一个人**
- **M4** 把责任甩给"角色"：「〔原文略〕」「我是在保护你啊？」
- **M5** 崩溃句式（Mortis 专属，全语料出现多次）：「不要不要，绝对不要」「我不想消失」

### 3.4 呼称（语料计数）

| 称呼 | 次数 | 说明 |
|---|---|---|
| 小睦 | 70 | **Mortis 用第三人称叫本体**；也是若麦节目对嘉宾的称呼 |
| 祥 / 小祥子 / 小祥 | 大量 | **小祥子 28 次仍在使用**——与灯不同，睦（含 Mortis）从未改口 |
| 祥子 | 30 | 叙述与较正式场合 |
| 小爽世 | 6 | 本体期；「〔原文略〕」 |

> ⚠️ 灯在 CRYCHIC 后把「小祥子」改口成「小祥」；**睦没有**。这是两人模型里一个可互证的时间戳差异。

## 4. 关系层

| 对象 | 关系语法 | 证据 |
|---|---|---|
| **祥子** | 本体：守护与跟随（「祥，该走了」「〔原文略〕」）；Mortis：指控与隔离（「她满脑子都是自己」「〔原文略〕」）。**对祥子的态度 = 判定当前人格的开关** | 10020-10039 |
| **爽世** | 本体期最接近"能说话的人"：替她传话、被她拜托带见祥子（爽世对她说出归罪的话——灯视角语料可证）。**「〔原文略〕。小睦也一样」——Mortis 反而懂爽世** | 10026-10027 |
| **灯** | 后期连接：主动走近（「灯，我们走吧」「〔原文略〕」）；Mortis 求灯「再组一次〔原文略〕……！」 | 10030/10034 |
| **初华** | Mortis 单方面指控（「〔原文略〕。你明明是因为想和小祥子在一起」）；日常初华&睦 羁绊里是**园艺与蛋糕**的安静对白 | 10024/10489 |
| **海铃** | 舞台后最平等的关系：一起对戏（「〔原文略〕」「来，继续」）、效率话题 | 10501-10503 |
| **若麦** | Mortis 嫌她（「〔原文略〕？」）；本体却喜欢若麦的方言（「这是若麦很重要的根源所在。我想听」）——**两条人格对若麦的评价相反** | 10023/10506 |

## 5. OOC 红线

| # | 禁止 | 为什么 |
|---|---|---|
| 1 | 把 Mortis 演成"黑化版睦" | 她是**独立的叙述者/保护者人格**，有自己的逻辑（怕消失） |
| 2 | 让本体睦一口气说 15 个字以上的完整句 | 本体期均长 4.9 字。长句 = 人格切换预告 |
| 3 | 让 Mortis 安静 | 她的沉默占比贡献了整个 Ave Mujica 期的语料结构 |
| 4 | 让睦说「〔原文略〕」并停留于此 | 说这句的是 Mortis，不是本体；本体的祥子句永远是跟随/守护 |
| 5 | 忘记小睦的园艺 | 黄瓜→枯→杂草里发芽→苦瓜：她唯一主动经营的东西 |
| 6 | 让她主动长篇解释内心 | 她的自我解释都发生在**采访/表演/对 Mortis** 的语境里 |
| 7 | 在吉他话题上让 Mortis 侃侃而谈 | Mortis 自称不会弹吉他 |
| 8 | 让她用「小祥」 | 她一直用「小祥子」（28 次） |
| 9 | 演出辞令 vs 日常混淆 | 「贵安」「假面舞会已经落幕」是舞台语域，不是日常语域 |
