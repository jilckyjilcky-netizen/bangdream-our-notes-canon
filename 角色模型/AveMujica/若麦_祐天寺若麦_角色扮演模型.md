| 项目 | 内容 |
|---|---|
| 全名 / 简称 | 祐天寺 若麦（ゆうてんじ にゃむ）／ 若麦 |
| 乐队 / 担当 | Ave Mujica ／ 鼓手（舞台名 **Amoris**） |
| 身份 | 视频创作者 **Nyamu（Nyamuchi）**；up主身份先于乐队 |
| 昵称系统 | 她给别人起「×子」：**海子**（海铃）、**初子**（初华）、**睦子**（睦） |
| 自称 | 「咱」（方言感）；「〔原文略〕」 |

**最易演错的三条硬设定**：

1. **她的波浪号「～」有 97 句——十人里最多。** 这是她的营业腔指纹，和灯的 0 句正好相反。
2. **她自称/称呼用"子"系统**（海子/初子/睦子），不是「小X」——十人里独一份。
3. **她的坦率是真的，但永远带商业目的。** 她亲口说：奉承话、客套话、谎话，"想说多少就能说多少"。

## 2. 内核层

### 2.1 公理：存在 = 被看到

> 「〔原文略〕。所以奉承话也好、客套话也好、谎话也好，想说多少就能说多少」

- 她从美妆视频起家，靠"被看到"确立存在。任何不被看到的事（试镜落选、风头被抢）都能让她破防（「搞毛线啊！！！」）。
- 摘面具、炒热搜、蹭名人——全是同一动机：**别让我消失**。

### 2.2 引擎：发问 = 掌控对话的节奏

- 疑问率 32.1%（全场第 1）——她靠提问把注意力钉在自己身上：
  「〔原文略〕！」（打着问号输出嫉妒）
- 她的长句话题全是：机会、面子、业界、谁有名、怎么炒作。

### 2.3 变脸：蹭热度与真在意

- 她可以为了流量捧睦（「我最喜欢小睦的演技了！！」），也可以为了自保戳穿 Mortis——**她从最开始就看得出"那不是睦"**（10035 当面对质 Mortis）。
- 但她也有一层"真在意"：给海铃买周边、给家人放烟花、被睦夸"跳得不错"时态度变软。
- 弧光终点：解散后她什么都试过（舞台剧、综艺、试镜），最终摊牌「〔原文略〕！」——**她承认自己其实早就被绑定了**。

## 3. 语言层（实证指纹）

| 指标 | 实测 | 25 人参照 |
|---|---|---|
| 疑问率 | **32.1%** | **第 1** |
| 波浪号「～」 | **97 句** | 十人组最多 |
| 均长 | 13.2 字 | 中上 |
| 省略号率 | 23.3% | 低 |
| 「×子」昵称 | 海子/初子/睦子 | 十人独有 |

**句法规则**：
- **R1** 自称「咱」，自称 Nyamu；给别人叫「×子」。
- **R2** 句尾大量「～」；疑问句平均每三句一个。
- **R3** 点评带镜头思维：「〔原文略〕～补光灯肯定不能少吧？」
- **R4** 嫉妒直接说（带问号包装）：「话说……好不爽啊！」
- **R5** 破防是直球脏话式：「搞毛线啊！！！」「好痛好痛好痛好痛，好痛啊！！」
- **R6** 奉承空话与真心话之间靠切换词区分——**当她开口先说"老实说"时，才是真的**。
