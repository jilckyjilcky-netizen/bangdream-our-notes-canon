# Our Notes 资料库工具链 · 方法与实现

> **这不是素材包。** 这里只有**方法、统计和工具**：怎么把一批中文对话语料，变成"可量化的人物说话方式"，
> 再做成程序能检索、能直接投喂给人设扮演的资产。
>
> 语料本身**不随仓库提供**（原作要素版权属 Bushiroad / Craft Egg / Ishimori，详见 [NOTICE.md](NOTICE.md)）。

---

## 一、整体思路

一句话：**先把台词按人分好，再把"怎么说"变成数字，最后把数字翻成人设资产。**

```
原始对话（不随仓库提供）
   │ ① 切分与归属：按说话人精确匹配，联句计入双方
   ▼
每人一份全量台词合集（素材全量/按角色全量 版式）
   │ ② 统计：定口径 → 17 项语言指标 → 全库横向对比表
   ▼
语言指纹（角色模型/指纹/ 30 份 + _全角色指纹对比.md）
   │ ③ 打分器：把"像不像"变成偏差分排序（who）
   │ ④ 规则化：把指标翻成"能照着写"的规则与人设资产
   ▼
人设资产（人设skill/ 角色卡/ 世界书/ 系统提示词/ 扮演模型）
   │ ⑤ 接口：同一份数据，MCP 与 CLI 两个入口
   ▼
可检索知识库（资料库/kb.json + mcp-canon/ 17 个工具）
```

## 二、五步各自的实现

| 步 | 做什么 | 代码 |
|---|---|---|
| ① 归属 | 按说话人把语料归属到角色：**精确匹配**（不做子串猜测，避免「祥子的声音」算成祥子）；联句「A・B」**计入双方**；泛用配角与"幼年版"等特殊角色显式排除 | `工具/corpus_attribute.mjs` |
| ② 统计 | 每人 17 项指标（句长均值/中位数/最长句、≤6 字占比、省略号率、疑问率、感叹率、口吃率、「小X」呼称率、含我率、歌词三项…），并生成全库横向对比表 | `工具/fingerprint_full.mjs` |
| ③ 打分 | `who`：把输入拆句 → 估计语料级特征 → 与每人登记指标比偏差 → 排序。**多句聚合明显优于单句**（单句 top1 仅 11%，5 句 15.8%，随机基线 4%） | `mcp-canon/canon-tools.mjs` |
| ④ 规则化 | 指标 → 规则（"省略号是底色""感叹号是句号"这类），再落成人设 skill / 角色卡 / 世界书 / 系统提示词 | `人设skill/`、`角色卡/`、`世界书/`、`角色模型/` |
| ⑤ 接口 | `kb.json` 一份数据，MCP 服务端（17 工具，stdio + streamable-http 两条传输）与 CLI 复用同一份实现 | `mcp-canon/`、`工具/canon.mjs` |

## 三、三个教训（这套方法最容易踩的坑）

1. **口径必须先定，否则数字会自己打架。**
   同一批台词，"按行"和"按台词条目"两种单位算出来的平均句长差 **1.7 倍**（7.91 字 vs 13.55 字）。
   定案是**一句 = 一行台词**——那才是模型实际会生成、读者实际会读到的单位。

2. **别拿人工精选的样本当基线。**
   波浪号基线最初从"精选台词库"派生（挑中 1 条带「～」就判该角色爱拖音），
   结果一位全量语料里 **0 次**使用波浪号的角色被判定"该用波浪号"，
   每次输出都恒定吃一维偏差，同一段台词的排名从第 5 掉到第 16。
   改成按**全量语料的实际使用率**判定后恢复正常。

3. **精选台词库有系统性偏差。**
   它是"有戏"的句子，不是随机抽样：短句占比、疑问率、省略号率都系统性偏离语料真实分布。
   拿它当风格范本、或拿它出盲测题，会继承这个偏移——所以 `stats` 工具里有逐人偏差表。

> 另有一条硬边界：**单句猜人不可当真**。它是偏差分排序，不是判定；给 ≥3 句才有实用价值。

## 五、跑起来

零依赖，Node 18+（实测 v24）：

```bash
node mcp-canon/_selfcheck.mjs      # 一行自检（工具数 / 角色数 / 事件数）
node mcp-canon/_test-tools.mjs     # 工具层断言（离线）
node mcp-canon/_test-http.mjs      # HTTP 传输 28 项断言（进程内起服务）
node 工具/check_kb.mjs             # 知识库完整性

node mcp-canon/canon-mcp-server.mjs          # stdio
node mcp-canon/canon-mcp-http.mjs            # → http://127.0.0.1:8787/mcp
node 工具/canon.mjs speech 疑问率             # 全库排名
node 工具/canon.mjs who '我、我没输！' '……是这样吗。'
node 工具/canon.mjs skill 祥子 all            # 人设 skill 全文
```

**构建链（① ② ④ 步）需要自备语料**，本仓库不含；没有语料时检索与人设资产仍可正常使用
（`kb.json` 已随仓库提供）。
